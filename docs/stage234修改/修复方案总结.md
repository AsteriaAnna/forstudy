3. 实现 `_compute_timefreq_features` 中的 wavelet_entropy 计算
4. 更新特征名称列表，添加 `wavelet_entropy`
5. 更新文档字符串

#### wavelet_entropy 计算方法
```python
# 使用所有小波系数的能量分布计算熵
all_coeffs = []
for c in coeffs:
    all_coeffs.extend(c.flatten())
energy_array = all_coeffs ** 2
total_energy = np.sum(energy_array)
if total_energy > 1e-10:
    p = energy_array / total_energy
    p = p[p > 1e-10]
    wavelet_entropy = -np.sum(p * np.log2(p + 1e-10))
else:
    wavelet_entropy = 0.0
```

### 3. 统一 ID 规则实现 🔑

- 正则表达式不一致：`\d` vs `\d+`

- [core/id_generator.py](file:///C:/Users/Asteria/Documents/代码/作业/论文/project/v16-project/missyou/core/id_generator.py)

1. 更新 `id_generator.py` 中的正则表达式：
   - `PATTERN_1` 从 `r'^c_(\d)_\d{3}\.csv$'` 改为 `r'^c_(\d+)_(\d+)\.csv$'`
